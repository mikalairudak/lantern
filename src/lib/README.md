# lib

Everything under the React layer: the data contract, the stream, live generation on the server, and what the client and the server share. Tests sit beside each module and never call a live service: the model is the AI SDK's mock or a fake Claude API, and Postgres is PGlite.

The files at the top: `site.ts` (the one public address), `same-site.ts` (only Lantern's pages may post to a route that counts or spends), `server-timing.ts`, `browser-storage.ts` (every key kept in a visitor's browser, which `/privacy` reads, and the owner's mark, which it leaves out), `lab-matrix.ts` (the shape of a `/lab/matrix` entry), and `repo-hygiene.ts` (the rules for what may be committed, which its test holds every tracked file to, the `commit-msg` hook each message, and the pull request check each pull request's branch name, title and body).

## Rules that hold here

- **No component.** Nothing here renders, and nothing here imports a feature, which lint holds with no exception (`FEATURE_IMPORTS` in `eslint.config.mjs`).
- **Server modules refuse a browser.** A module that holds a key or a driver throws if a browser loads it, and `live/server-only.browser.test.ts`, `events/server-only.browser.test.ts` and `places/server.browser.test.ts` check each one.
- **The contract is imported, never copied.** A shape or vocabulary of the day or the request lives in `schema/` alone.
